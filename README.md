# מצ׳אטבוט לסוכן — הרצאה חיה

מצגת הרצאה בעברית: שלד קבוע של שקפים, במה חופשית עם טקסטים, תמונות, צורות ורכיבים חזותיים, ניסוי אינטראקטיבי, עורך תוכן ושבע ערכות צבע.

העיצוב בהשראת מצגות Google I/O: כותרת גדולה, הרבה שטח ריק ומסר אחד בכל רגע. פקדי ההצגה מופיעים בהזזת העכבר או ב־Tab; ברירת המחדל היא במה נקייה.

## פתיחה ללא התקנה

פתחו את `dist/index.html` בלחיצה כפולה. כל הקוד והעיצוב כלולים בקובץ; לא צריך אינטרנט, Node או חשבון כדי להציג ולערוך אותו. מומלץ להשתמש ב־Chrome או Edge עדכניים.

בעורך בוחרים **הורדת ההרצאה למחשב** כדי לקבל HTML עצמאי עם התוכן העדכני. אפשר להעביר אותו למחשב אחר. שינויים בעורך אינם משנים את קובץ המקור שעל הדיסק: הם נשמרים בדפדפן, וכדי לשמור קובץ חדש צריך להוריד עותק.

הגרסה המקוונת שומרת את העריכות באותו מכשיר ודפדפן בלבד, ואינה מסנכרנת אותן לחשבון או למחשבים אחרים. קובץ HTML שהורדתם או ייצוא JSON הם הגיבוי הנייד.

## בזמן ההרצאה

| פעולה | מקש / כפתור |
| --- | --- |
| הצעד הבא | רווח, חץ שמאלה, Page Down |
| הצעד הקודם | חץ ימינה, Page Up |
| מעבר ישיר לשקף | הנקודות בתחתית הבמה |
| מסך מלא | F או כפתור מסך מלא; F11 הוא חלופה בדפדפן |
| יציאה ממסך מלא / סגירת חלונית | Esc |
| הערות המרצה על המסך | N |
| החשכת המסך | B |
| תוכן ודוגמאות | עריכה |
| פלטת צבעים | עיצוב |

שלט ששולח Page Down / Page Up נתמך. בזמן הקלדה בעורך, מקשי ההצגה אינם פעילים. כשהמיקוד על כפתור, רווח מפעיל את הכפתור כנהוג בדפדפן.

שקף אחד יכול להיות כמה צעדים. רווח מתקדם צעד־צעד בתוך השקף, וכשנגמרים הצעדים הוא עובר לשקף הבא. המונה בסרגל מציג את מספר השקף מתוך הסך הכול.

## סוגי השקפים

| הסוג | מה הוא עושה |
| --- | --- |
| משפט גדול | כותרת אחת, מילה מודגשת ומשפט קצר מתחת. |
| הדגמה חיה | מחזיק את הבמה בזמן שעוברים לכלי עצמו. הפרומפט נשמר בשקף, מועתק בלחיצה ואינו מוקרן. |
| מילים שנחשפות | מילה אחת בכל צעד עם משפט אחד מתחתיה; הקודמות נשארות עמומות. |
| חתיכות של שפה | משפט שנשבר לחתיכות צבעוניות, כמו שהמודל רואה אותו. |
| תמונה | תמונה שהיא השקף, עם כותרת ומשפט מעליה. |
| מספר ענק | מספר אחד שממלא את הבמה ומטפס אליו, עם יחידה ומשפט. |
| שניים זה מול זה | שני צדדים על אותה במה. כל צעד מדליק צד אחד. |
| טיימר | ספירה לאחור לתרגול או להפסקה, שמתחילים ועוצרים על השקף. |
| במה חופשית | שקף ריק שמרכיבים מתיבות טקסט, תמונות וצורות חופשיות. |
| צ׳אטבוט מול סוכן | הניסוי האינטראקטיבי, עם החלפת דוגמה לפי הקהל. |

השלד הנוכחי הוא חלק א׳ של ההרצאה: אותה שאלה בגוגל ובצ׳אט, שלוש משפחות של מה שמחשב יודע לעשות, מסמך שנשמע אמיתי, פירוק המושג ״מודל שפה גדול״, רשת החיבורים, חתיכות של שפה, המצאה בביטחון, והמעבר לחלק השני.

## עריכת טקסט על הבמה

כשהעורך פתוח, **לחיצה כפולה על כל טקסט שמוקרן** פותחת אותו לעריכה במקום שבו הוא יושב — הכותרת, המשפט שמתחת, המילים שנחשפות, הצדדים, המספר, וגם הטקסטים של הניסוי. הטקסט לא זז ולא משנה גודל; הוא נשאר בדיוק איפה שהוא. יוצאים ב-Esc, ב-Enter, או בלחיצה במקום אחר.

כל שדה שומר על האורך המרבי שלו, וההודעה על המסך אומרת מה המגבלה אם חורגים ממנה.

להפוך טקסט לאובייקט שאפשר לגרור בחופשיות זו פעולה נפרדת ומכוונת — הכפתור בעורך, בתוך השקף.

## עזרים למרצה

- **N** פותח וסוגר את הערת המרצה של השקף הנוכחי על גבי הבמה. שימושי בחזרות ובמצגת ממחשב אחד; אם המקרן משכפל את המסך, הקהל יראה אותה גם הוא.
- **B** מחשיך את הבמה לגמרי, כשרוצים שהקהל יסתכל עליך ולא על המסך. לחיצה נוספת או מעבר לשקף הבא מחזירים אותה.
- שקף **טיימר** מציג ספירה לאחור גדולה. מתחילים, עוצרים ומאפסים בכפתורים שעל השקף, והספירה ממשיכה גם אם החלפת ערכת צבע באמצע. כשהזמן נגמר המספר מהבהב.

## תמונות

יש שלוש דרכים, וכולן מתחילות בכפתור **עריכה** בסרגל התחתון:

1. **תמונה חופשית על כל שקף** — במקטע השקף, תחת **אובייקטים חופשיים**, בוחרים **תמונה**. מעלים קובץ, ואז גוררים את התמונה על הבמה ומשנים את גודלה מהידית שבפינה. אפשר גם לקבוע מיקום, מידות, סיבוב, שקיפות, עיגול פינות וסדר שכבות דרך העורך.
2. **תמונה מאחורי הטקסט, בכל שקף שהוא** — בתוך השקף שרוצים, תחת **רקע הבמה**, בוחרים **תמונה משלך**. מיד מתחתיו נפתח כפתור **בחירת תמונה**. התמונה נכנסת מאחורי הכותרת עם הצללה שמשאירה את הטקסט קריא.
3. **שקף שכולו תמונה** — בראש העורך יש **הוספת שקף חדש בסוף המצגת**; בוחרים שם **תמונה** ולוחצים **הוספה**. השקף החדש נפתח מיד עם שדה התמונה שלו.

בשני המקרים בוחרים **בחירת תמונה** מהמחשב. התמונה מכווצת אוטומטית (עד 1920 פיקסלים, בפורמט WebP) ונשמרת בתוך התוכן עצמו — ולכן היא נוסעת עם קובץ ה-HTML שמורידים, ונפתחת גם בלי אינטרנט. צילום מסך רגיל יורד בדרך כלל לכמה עשרות קילובייטים.

- **ממלאת את הבמה** — התמונה נחתכת לגודל המסך המלא, והכותרת מוקרנת מעליה על הצללה. מתאים לצילומים.
- **נכנסת בשלמותה** — התמונה נראית במלואה בלי חיתוך, והטקסט יושב מתחתיה. מתאים לצילומי מסך ותרשימים.

שדה **תיאור לקורא מסך** אינו מוקרן; הוא מיועד לנגישות.

## במה חופשית ואובייקטים

לכל סוג שקף אפשר להוסיף שכבה חופשית מעל התוכן הקבוע. אם רוצים לבנות קומפוזיציה מאפס, מוסיפים שקף מסוג **במה חופשית**.

1. פותחים **עריכה** ואת השקף הרצוי.
2. תחת **אובייקטים חופשיים** מוסיפים **טקסט**, **תמונה**, **צורה** או **רכיב חזותי**.
3. במסך רחב, כשהעורך פתוח לצד הבמה, לוחצים על האובייקט וגוררים אותו. הידית בפינה משנה את גודלו. גריד של 5% וקווי יישור לאובייקטים אחרים מופיעים בזמן הגרירה; אפשר לבטל את ההצמדה מסרגל הבמה או מפאנל האובייקט. במסך צר בוחרים **עריכת במה** כדי לכווץ את הפאנל לרצועה תחתונה.
4. לחיצה כפולה על תיבת טקסט מאפשרת להקליד ישירות עליה. אפשר גם ללחוץ פעמיים על כותרת, מילה מודגשת, כיתוב, שם כלי או יחידה קיימים — המערכת הופכת אותם לתיבה ומתחילה עריכה מיד. לחיצה אחת במקום ריק או בפאנל מסיימת את ההקלדה ושומרת אותה; גם Esc או Ctrl+Enter מסיימים.
5. בחירת אובייקט פותחת מעל הבמה סרגל מהיר. בטקסט יש תפריט **מראה הטקסט** עם צבע אחיד, צבעוני או קו מתאר. באובייקטים מופיעים גם כניסה, יציאה והצמדה; בחירת תנועה מציגה אותה מיד כתצוגה מקדימה. החצים מזיזים את האובייקט הנבחר על קווי הגריד.
6. דרך פאנל האובייקט אפשר להקליד מיקום ומידות מדויקים, לסובב, לשנות שקיפות, לשכפל, למחוק ולהעביר קדימה או אחורה בין השכבות.

לטקסט חופשי יש גודל, משקל, יישור וצבע עצמאיים. תחת **מראה** אפשר לבחור צבע אחיד, טקסט צבעוני בגוון הערכה, או קו מתאר. האפשרות הצבעונית אינה תלויה יותר בתנועת הכניסה ״מילה אחרי מילה״.

במקטע **טקסט על הבמה** אפשר להפוך כותרת, מילה מודגשת, כיתוב, שם כלי או יחידה קיימים לתיבה חופשית בלי להקליד אותם מחדש. התיבה נשארת מסונכרנת עם שדה התוכן; **החזרה לתבנית** מסירה את התיבה ומחזירה את המיקום המקורי.

הצורות המובנות הן מלבן, עיגול, קו, חץ, כוכב, כתם וטבעת. לכל צורה אפשר לבחור צבע מילוי, צבע קו ועובי קו. אפשר לשלב עד 40 אובייקטים חופשיים בכל שקף.

ספריית הרכיבים החזותיים כוללת כרטיס אקורדיון שמתרחב בריחוף, משטח זכוכית נוזלית ושדה כוכבים מונפש. כולם נבנו מחדש ב־HTML/CSS מקומי, ניתנים לשינוי צבע וטקסט ואינם דורשים React, תמונה מרוחקת או חיבור רשת.

## תנועה, רקע ומעברים

לכל שקף בוחרים בעורך שלושה דברים, והבחירה נשמרת עם התוכן:

- **מראה הטקסט** — צבע אחיד, צבעוני (מדורג בצבעי הערכה), או קו מתאר. חל על הכותרות של השקף.
- **תנועת הכניסה** — איך התוכן מגיע לבמה: עלייה רכה, התבהרות, חשיפה, מילה אחרי מילה, התקרבות, או בלי תנועה.
- **רקע הבמה** — קשתות אור, רשת, חלקיקים, זוהר, טבעות, קרני אור, גלים, הילה, תמונה משלך, או רקע נקי.
- **מעבר לשקף הזה** — הצלבה, החלקה, זום או חיתוך. כל שקף קובע בנפרד כיצד הוא נכנס מהשקף הקודם.

לכל אובייקט חופשי אפשר לבחור גם **כניסה** ו־**יציאה** משלו. הן פועלות לטקסט, תמונות, צורות ורכיבים חזותיים, ומסתיימות לפני שהתוכן של השקף הבא נכנס כדי שלא יסתירו זו את זו. מעבר השקף פועל רק כשעוברים שקף, לא בין צעדים בתוך אותו שקף.

ערבוב של רקעים ותנועות הוא מה שמונע מהמצגת להיראות אותו דבר בכל שקף. אפשר לבחור לפי המסר: חלקיקים מאחורי רשת נוירונים, רשת מאחורי הדגמה טכנית, זוהר מאחורי שורת מפתח.

כל האנימציות מכבדות את העדפת ״הפחתת תנועה״ של מערכת ההפעלה, ונכבות אוטומטית כשהיא מופעלת.

## עריכה והתאמה לקהל

פותחים **עריכה**. במסך רחב הפאנל נשאר לצד הבמה כדי שאפשר יהיה לגרור אובייקטים בזמן העריכה. בראש הפאנל מוסיפים שקף חדש מכל סוג. מתחתיו כל שקף הוא מקטע נפרד: אפשר לשנות טקסטים, להוסיף אובייקטים חופשיים, להזיז שקף למעלה ולמטה ולמחוק אותו. שדות ״הערת מרצה״ ו״הפרומפט״ אינם מוקרנים לקהל.

לניסוי יש חבילת דוגמאות משלו:

1. פתחו את מקטע **דוגמאות לקהלים** ובחרו **שכפול לקהל אחר**.
2. תנו לדוגמה שם, ושנו את המשימה, התשובה והשלבים.
3. בחרו בין 2 ל־6 שלבים, עם תיאור קצר ותוצר לכל שלב. אפשר לשמור עד 20 דוגמאות בחבילה.
4. הורידו את ההרצאה למחשב, או השתמשו ב־**ייצוא תוכן** לשמירת JSON.

**ייבוא תוכן** מחליף את חבילת התוכן הנוכחית לאחר בדיקה. ייצאו גיבוי אם תרצו לשמור את החבילה הקודמת. קובץ שגוי נדחה בלי להחליף את התוכן. שבע ערכות צבע: פחם ותכלת, לבן וכחול, בורדו ולבן, יער ומנטה, פחם וענבר, דיו ונייר, וסגול ולילך.

הניסוי הוא המחשה בלבד. הוא לא שולח הזמנות, לא פונה למודלי AI ולא מפעיל כלים חיצוניים. ההדגמות החיות נעשות בכלים האמיתיים, במקביל למצגת.

## פיתוח

דרוש Node.js בגרסה 20 ומעלה. אין תלויות npm להתקנה.

```powershell
npm run build
npm test
npm start
```

התצוגה המקומית זמינה בכתובת `http://127.0.0.1:4173`. לאחר שינוי במקור יש להריץ שוב `npm run build` ולרענן את הדפדפן. אפשר לשנות את פורט ההגשה באמצעות משתנה הסביבה `PORT`.

חבילת תוכן ניידת מוגבלת ל־2.4MB בסך הכול כדי שהשמירה בדפדפן, הייבוא והורדת ה־HTML יישארו אמינים. התמונות מכווצות לפני השמירה, ואם החבילה מלאה מוצגת הודעה ולא מוחלפת העריכה הקיימת.

מבנה המקור:

- `src/content.json` — התוכן: מערך השקפים, הדוגמאות וגרסת הפורמט.
- `src/core.js` — טבלת סוגי השקפים, בדיקת תוכן וחוקי ההתקדמות, ללא תלות בדפדפן.
- `src/shell.html`, `src/styles.css`, `src/app.js` — מעטפת, עיצוב ורכיבי השקפים והעורך.
- `scripts/build.mjs` — אריזת המקור ל־HTML עצמאי; `scripts/serve.mjs` — תצוגה מקומית בלבד.
- `tests/core.test.mjs` — בדיקות התוכן, הניווט והאריזה.
- `dist/index.html` — התוצר הנייד והקובץ שמוגש באתר. נכלל ב־Git בכוונה.

סוג שקף חדש מוגדר במקום אחד, `SLIDE_TYPES` שב־`src/core.js`: השדות שלו, מספר הצעדים שלו והתווית בעורך. אובייקטים חופשיים מוגדרים בטבלאות `OBJECT_TYPES`, `SHAPES` ו־`TEXT_STYLES`; הוספת ציור או אינטראקציה לבמה נעשית ב־`src/app.js` וב־`src/styles.css`.

תנועה, רקע ומעבר מוגדרים באותה צורה: `MOTIONS`, `BACKDROPS` ו־`TRANSITIONS` ב־`src/core.js` הן טבלאות של מפתח מול שם בעברית. המפתח הוא מה ש־CSS נתלה עליו (`motion-blur`, `backdrop-grid`, `[data-transition="push"]`), והשם הוא מה שמופיע בעורך. הוספת אפשרות היא שורה בטבלה ובלוק CSS.

כדי להפוך תוכן שערכתם לברירת המחדל של הפרויקט, ייצאו JSON, החליפו בו את `src/content.json` ובנו שוב. אריזת HTML מהעורך מייצרת מזהה חדש כדי שדפדפן במחשב היעד לא יחליף את התוכן בגרסה ישנה ששמר בעבר.

## פרסום ב־GitHub Pages

`.github/workflows/pages.yml` מריץ בדיקות, בונה את `dist/index.html` ומפרסם אותו בכל דחיפה ל־`main`.

פעם אחת בלבד צריך להדליק את Pages במאגר: **Settings → Pages → Source: GitHub Actions**. לאחר מכן כל דחיפה ל־`main` מעדכנת את האתר.

אין לשמור מפתחות או אסימוני גישה בפרויקט.

## המשך הפרויקט

ראו `PROJECT.md` להחלטות, סטטוס וכיווני המשך, ו־`AGENTS.md` לכללי תחזוקה. `AGENTS.md` הוא קובץ ההנחיות המשותף לכל סוכני ה־AI שעובדים על הפרויקט; `CLAUDE.md` רק מפנה אליו, כדי שלא יהיו שתי גרסאות של אותם כללים.
