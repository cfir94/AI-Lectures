# מצ׳אטבוט לסוכן — הרצאה חיה

אפליקציית הרצאה בעברית עם שני שקפים, ניסוי אינטראקטיבי, עורך תוכן ושלוש ערכות צבע.

העיצוב בהשראת מצגות Google I/O: כותרת גדולה, הרבה שטח ריק ומסר אחד בכל רגע. בניסוי כל לחיצה מחליפה את הפעולה הנוכחית. פקדי ההצגה מופיעים בהזזת העכבר או ב־Tab; ברירת המחדל היא במה נקייה.

## פתיחה ללא התקנה

פתחו את `dist/index.html` בלחיצה כפולה. כל הקוד והעיצוב כלולים בקובץ; לא צריך אינטרנט, Node או חשבון כדי להציג ולערוך אותו. מומלץ להשתמש ב־Chrome או Edge עדכניים.

בעורך בוחרים **הורדת ההרצאה למחשב** כדי לקבל HTML עצמאי עם התוכן העדכני. אפשר להעביר אותו למחשב אחר. שינויים בעורך אינם משנים את קובץ המקור שעל הדיסק: הם נשמרים בדפדפן, וכדי לשמור קובץ חדש צריך להוריד עותק.

הגרסה המקוונת שומרת את העריכות באותו מכשיר ודפדפן בלבד, ואינה מסנכרנת אותן לחשבון או למחשבים אחרים. גם במצב מקומי שמירת הדפדפן עשויה להשתנות לפי מדיניות הדפדפן או מיקום הקובץ. קובץ HTML שהורדתם או ייצוא JSON הם הגיבוי הנייד.

## בזמן ההרצאה

| פעולה | מקש / כפתור |
| --- | --- |
| הצעד הבא | רווח, חץ שמאלה, Page Down |
| הצעד הקודם | חץ ימינה, Page Up |
| מעבר ישיר בין שקפים | 01 / 02 בתחתית הבמה |
| מסך מלא | F או כפתור מסך מלא; F11 הוא חלופה בדפדפן |
| יציאה ממסך מלא / סגירת חלונית | Esc |
| תוכן ודוגמאות | עריכה |
| פלטת צבעים | עיצוב |

שלט ששולח Page Down / Page Up נתמך. בזמן הקלדה בעורך, מקשי ההצגה אינם פעילים. כשהמיקוד על כפתור, רווח מפעיל את הכפתור כנהוג בדפדפן. הזזת העכבר או שימוש במקש Tab מחזירים את סרגל השליטה.

## התאמה לקהל

1. פתחו **עריכה** ובחרו **שכפול לקהל אחר**.
2. תנו לדוגמה שם, ושנו את המשימה, התשובה והשלבים.
3. בחרו בין 2 ל־6 שלבים, עם תיאור קצר ותוצר לכל שלב. אפשר לשמור עד 20 דוגמאות בחבילה.
4. הורידו את ההרצאה למחשב, או השתמשו ב־**ייצוא תוכן** לשמירת JSON.

**ייבוא תוכן** מחליף את חבילת התוכן הנוכחית לאחר בדיקה. ייצאו גיבוי אם תרצו לשמור את החבילה הקודמת. קובץ שגוי נדחה בלי להחליף את התוכן. ערכות הצבע: פחם ותכלת, לבן וכחול, בורדו ולבן.

על הבמה מופיעים שם הפעולה והתוצר הקצר בלבד. שדות ״הערת מרצה״ בעורך מיועדים להסבר שלך ואינם מוקרנים לקהל. כותרת הניסוי משמשת ככותרת מצב הצ׳אטבוט; במצב סוכן שם הפעולה הופך לכותרת המרכזית.

הניסוי הוא המחשה בלבד. הוא לא שולח הזמנות, לא פונה למודלי AI ולא מפעיל כלים חיצוניים. דוגמאות חיות בכלים אמיתיים דורשות אינטרנט בנפרד.

## פיתוח

דרוש Node.js בגרסה 20 ומעלה. אין תלויות npm להתקנה.

```powershell
npm run build
npm test
npm start
```

התצוגה המקומית זמינה בכתובת `http://127.0.0.1:4173`. לאחר שינוי במקור יש להריץ שוב `npm run build` ולרענן את הדפדפן. אפשר לשנות את פורט ההגשה באמצעות משתנה הסביבה `PORT`.

מבנה המקור:

- `src/content.json` — תוכן ברירת המחדל, דוגמאות וגרסת פורמט.
- `src/core.js` — בדיקת תוכן וחוקי ההתקדמות, ללא תלות בדפדפן.
- `src/shell.html`, `src/styles.css`, `src/app.js` — מעטפת, עיצוב ורכיבי השקפים והעורך.
- `scripts/build.mjs` — אריזת המקור ל־HTML עצמאי; `scripts/serve.mjs` — תצוגה מקומית בלבד.
- `tests/core.test.mjs` — בדיקות התוכן, הניווט והאריזה.
- `dist/index.html` — התוצר הנייד והקובץ שמוגש באתר. נכלל ב־Git בכוונה.

כדי להפוך תוכן שערכתם לברירת המחדל של הפרויקט, ייצאו JSON, החליפו בו את `src/content.json` ובנו שוב. אריזת HTML מהעורך מייצרת מזהה חדש כדי שדפדפן במחשב היעד לא יחליף את התוכן בגרסה ישנה ששמר בעבר.

## העלאה ל־GitHub

התיקייה כבר כוללת Git. צרו מאגר ריק ב־GitHub, ואז מתוך תיקיית הפרויקט:

```powershell
git status
git add .
git commit -m "Update interactive lecture"
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin HEAD
```

אם אין שינויים חדשים, אין צורך ב־commit נוסף. אם `origin` כבר קיים, בדקו `git remote -v` לפני שינויו. פרסום ב־Sites הוא נפרד מ־GitHub ואינו יוצר עבורכם מאגר GitHub. אין לשמור מפתחות או אסימוני גישה בפרויקט.

להצגה דרך GitHub Pages אפשר לפרסם את תוכן `dist`, תוך הגדרת Pages בנפרד; הגדרות Pages אינן חלק מאב־הטיפוס הזה.
