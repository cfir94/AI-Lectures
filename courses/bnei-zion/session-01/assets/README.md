# Tool artwork provenance

Perplexity horizontal logo files were downloaded from the brand's published brand system:
https://live.standards.site/perplexity/logo

`perplexity-logo-cropped.svg` preserves the original Light logo paths and ink. Only the large empty presentation canvas/background was removed and the viewBox cropped so the actual mark is legible on a slide. No letterform was redrawn.

The remaining logos and lecture artwork are embedded from the presenter's existing `src/content.json` and `assets/tool-marks.json`. Their shapes and proportions are preserved. Raster/video lecture material was supplied by the presenter; the Figure video remains a separate local file beside the deck.
